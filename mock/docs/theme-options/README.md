# Theme options

Five visual theme options for the playground, plus the current app for comparison. Produced on 2026-10-20 from invented placeholder data. **No option is chosen yet.**

| Path | What |
|---|---|
| `options.md` | The write-up: research, the five options, trade-offs |
| `contrast-tables.md` | WCAG contrast tables for every option |
| `contact-sheet.png` | One-image overview of all options (start here) |
| `shots/` | Full-size screenshots, one folder per option (`0-current-app`, `1-spec-sheet`, `2-ink-and-scale`, `3-research-note`, `4-blueprint`, `5-analyst-desk`) |
| `source/` | Theme CSS (`d1`..`d5`, `shared.css`) and the tools that made the screenshots, contact sheet and contrast tables (`capture.mjs`, `sheet.mjs`, `sheet.html`, `contrast.py`, `contrast.md`) |

The tools were written for a scratch copy of the app and need their paths adjusted before reuse. Third-party reference screenshots used during research are deliberately not stored here.
